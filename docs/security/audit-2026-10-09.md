## Remediation round 2 (2026-10-09)

Again re-verified by security-reviewer and ux-reviewer. Runtime checks were run on this machine. Note: COMODO auto-contains freshly built unsigned test binaries. Contained runs have a virtualised filesystem, so writes such as `rtb.json` aren't real, and they sometimes hang at startup. Only uncontained runs count as runtime evidence below.

| ID | Status | Evidence |
