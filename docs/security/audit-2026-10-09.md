## Remediation round 4 (2026-10-09)

| U15 | Accepted, change reverted | A first attempt (`4f8ae80`) created the settings window hidden with `EnsureHandle()` and registered the tray icon explicitly. The security review (H-1, High, verified against WPF `Window.cs` 2564/2864/5398) found that WPF attaches a window's content only on first Show.
